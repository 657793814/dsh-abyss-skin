# 放入你的图片

把 **4–8 张你有版权/使用权的图片** 放在这个目录，命名按轮换顺序：

```text
01.jpg
02.jpg
03.jpg
04.jpg
```

要求：

- 建议 1440×1920 或更高；16:9、竖图都可以。竖图会以“模糊铺底 + 完整人像居中”显示，不裁脸。
- 支持 `.jpg` / `.jpeg` / `.png` / `.webp`。
- 不要放未授权的明星、成人演员或他人肖像；这个目录会被本地读取，但打包分发时应排除。
- 如果你有自定义启动视频：把它命名为 `skins/muse/user-boot.mp4`，运行 `python3 tools/render_muse.py --poster-only` 只生成海报。
- 如果让脚本用图片生成启动片：运行 `python3 tools/render_muse.py`。
- 生成后完全重启 DSH。
- 没有图片时，MUSE 使用内置的玫瑰金抽象占位图。
